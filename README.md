# Anniversary Redactle

A self-contained, playable Redactle-inspired anniversary puzzle. It uses plain HTML, CSS, and JavaScript and is ready for GitHub Pages.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.

## Customize the article

Edit the `article` object at the top of `app.js`. The title is the winning answer. Common connecting words are revealed automatically; guesses reveal matching word variations throughout the article.

## GitHub Pages

Publish from the repository's `main` branch and root folder in **Settings → Pages**.

This project is an unofficial personal tribute and is not affiliated with Redactle.
